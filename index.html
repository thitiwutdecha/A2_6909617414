CS100 A1: My First Learning Portfolio

Role: Individual Developer

Description:

พัฒนาเว็บไซต์ Learning Portfolio หน้าเดียวด้วยภาษา HTML และ CSS โดยทำหน้าที่เป็น Client ที่เปิดอ่านไฟล์บนเบราว์เซอร์ เพื่อฝึกฝนโครงสร้างพื้นฐานของเว็บและจัดระเบียบเนื้อหาแนะนำตนเอง

Skills:

HTML CSS Semantic HTML Web Fundamentals

Reflection (การสะท้อนคิด 4 ประเด็น):

  • 1. What I did (ฉันทำอะไร): ออกแบบโครงสร้างหน้าเว็บด้วย HTML5 สร้างส่วน About Me, What I Built, How I Built It และ Reflection พร้อมเขียนไฟล์ CSS แยกเพื่อกำหนดสี พื้นหลัง และขนาดตัวอักษร
  • 2. What I learned (ฉันเรียนรู้อะไร): ได้ฝึกสร้างเว็บด้วย HTML และ CSS เข้าใจบทบาทการทำงานร่วมกันระหว่างโครงสร้างและสไตล์ รวมถึงเข้าใจการทำงานของ Client ที่เปิดอ่านไฟล์เอกสารเว็บ
  • 3. Challenge (ปัญหาและความท้าทาย): ลืมคำสั่งบางตัว มีปัญหาเรื่อง semantic HTML และ path ของรูปภาพ ได้แก้ไขโดยค้นหาข้อมูลเพิ่มเติมจากสไลด์ของอาจารย์, ไฟล์ตัวอย่างใน Courseweb และเว็บไซต์ W3Schools จนแก้ปัญหาได้สำเร็จ
  • 4. Next step (ก้าวต่อไปในการพัฒนา): อยากปรับปรุงหน้าเว็บให้สวยงาม มีความเป็นระเบียบ และสามารถรองรับการแสดงผลบนอุปกรณ์หน้าจอขนาดต่างๆ เช่น สมาร์ทโฟนและแท็บเล็ตได้อย่างเหมาะสม (Responsive Web Design)
